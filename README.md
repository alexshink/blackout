# Blackout

Простая утилита, которая позволяет мгновенно наложить оверлэй поверх окон на всех мониторах, кроме выбранного.

## Зачем?

Для тех людей, которые работают с несколькими мониторами и иногда хотят переключиться на просмотр фильма или видео на одном из них, особенно ночью, когда остальные мониторы отвлекают и слепят. **Blackout** позволяет удобно выбрать активный монитор и затемнить остальные.

## А выключить монитор на кнопку?

При выключении мониторов ломается раскладка окон, которые были открыты на них. Данная утилита не отключает мониторы и не ломает раскладку окон, а просто создаёт "пелену" поверх рабочего стола.

## Как использовать?

1. Скачайте последнюю версию [здесь](https://github.com/alexshink/blackout/releases).
2. Запустите. Установка не требуется.
3. Включите:
    - комбинацией клавиш по умолчанию `Ctrl+Alt+B` (на macOS `Ctrl+Option+B`);
    - на Windows: `ЛКМ` по иконке в трее или `ПКМ` -> `Включить`;
    - на macOS: любой клик по иконке в строке меню -> `Включить`.

После включения активируется режим выбора монитора: на дисплее, где находится курсор, появляется зелёная рамка, а остальные дисплеи закрываются чёрной пеленой. Зелёная рамка обозначает активный дисплей, который останется видимым.

**Выбрать активный монитор:**
- курсором;
- стрелками на клавиатуре;
- цифрами `1`…`9`.

## macOS (Apple Silicon)

<details>
<summary><b>Спойлер</b></summary>
<br>

> Предсобранная версия для macOS предназначена для `Apple Silicon` (arm64) и совместима с Mac на чипах `M1`, `M2`, `M3`, `M4` и более новых поколений Apple Silicon. Если у вас Mac с процессором **Intel**, вы можете самостоятельно собрать программу по инструкции в разделе [Самостоятельная сборка на macOS](#самостоятельная-сборка-на-macos).

Предсобранная версия Blackout не подписана **Apple Developer ID**, поскольку для этого требуется платное участие в **Apple Developer Program**. Blackout — небольшая бесплатная программа без коммерческой монетизации, поэтому приобретение платной подписки для её распространения нецелесообразно.

В связи с этим при скачивании программы из интернета macOS может автоматически добавить к приложению метку карантина (`com.apple.quarantine`). Поэтому при запуске программы вы получите предупреждение от Finder `«Не удается открыть программу»`. Для корректного запуска необходимо следовать данной инструкции:

1. Распаковать `Blackout.app` из скачанного ZIP-архива. 
2. Открыть терминал и выполнить команду, где `path/to` путь к распакованному приложению `Blackout.app`:
    ```bash
    xattr -dr com.apple.quarantine path/to/Blackout.app
    ```

    > Данная команда удаляет метку карантина `com.apple.quarantine` из приложения.

3. Далее можно запускать `Blackout.app`. После запуска программы её иконка появится в **строке меню**, а не в Dock.

### Самостоятельная сборка на macOS

<details>
<summary><b>Спойлер</b></summary>
<br>

Далее рассматриваем пример установки с рабочего стола. Не забудьте заменить пути в командах на свои, если директория с репозиторием не на рабочем столе.

1. Установить [Apple Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools#Install-the-Command-Line-Tools-package-in-Terminal):

```bash
xcode-select --install
```

2. Установить `Rust` и `Cargo` через [rustup](https://rustup.rs):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

3. Склонировать или скачать данный репозиторий.

4. В том же терминале перейти в директорию с репозиторием

```bash
cd ~/Desktop/blackout
```

5. Собрать программу:

```bash
cargo build --release
```

6. Создать `.app`-файл:

```bash
sh scripts/macos-app.sh
```

В конце скрипт выведет к созданному `Blackout.app`. Это и есть исполняемый файл программы, его можно сразу запустить двойным кликом через Finder. Поздравляю, вы собрали программу!

> Cargo по умолчанию собирает программу под архитектуру текущего Mac. Поэтому на Apple Silicon будет создана `arm64`-сборка, а на Intel Mac — `x86_64`-сборка.

## Технические детали

Исходный код находится в этом репозитории.

- **Язык:** Rust
- **Windows:** нативный `Win32` API (crate `windows`)
- **macOS:** нативный `AppKit` (crates: `objc2`, `objc2-app-kit`)
- **Конфигурация:**
  - Windows: `%AppData%\blackout\config.toml`
  - macOS: `~/Library/Application Support/blackout/config.toml`
- **Зависимости при запуске:** сторонние `.dll` и `.dylib` не требуются
- **Результат сборки:**
  - Windows: `blackout.exe`
  - macOS: `Blackout.app`
